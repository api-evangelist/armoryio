# Armory.io

> Armory was an enterprise continuous delivery / continuous deployment company built around the open-source Spinnaker project (products: Armory CD Self-Hosted & Managed, Armory Continuous Deployment-as-a-Service / CDaaS, and the Armory Scale Agent for Spinnaker and Kubernetes). Armory was acquired by Harness; www.armory.io now redirects to harness.io and the CDaaS cloud service, developer portal, and status page are decommissioned. The documentation site and GitHub organization remain live.

This llms.txt was GENERATED by the API Evangelist enrichment pipeline from apis.yml and the repository artifacts (method: generated). No live Armory API surface exists to harvest.

## Docs
- [Armory Documentation](https://docs.armory.io/): Live documentation for Armory CD (self-hosted/managed), Spinnaker plugins, and the Scale Agent.
- [Harness Continuous Delivery](https://www.harness.io/products/continuous-delivery): Successor product after the Harness acquisition (www.armory.io redirects here).

## Source code
- [Armory GitHub organization](https://github.com/armory): 108 Apache-2.0 repositories of Spinnaker tooling.
- [plank — Spinnaker SDK for Go](https://github.com/armory/plank): Go client for Spinnaker microservices (Gate/Orca/Front50). Latest v4.2.3.
- [avm — Armory Version Manager](https://github.com/armory/avm): Installer for the Armory CDaaS CLI.
- [spinnaker-operator](https://github.com/armory/spinnaker-operator): Open-source Spinnaker Kubernetes Operator.
